# UI locale (en / de)

**Spec:** `specs/domain/settings.md`  
**Paths:** `paths.localeStorageKey` · `paths.i18nLibPath` · `paths.localesDir`

## Model

Audion/Checkion/Plexon-style nested JSON + `createTranslator` — no next-intl.

| Piece | Path |
|-------|------|
| Dictionaries | `apps/web/locales/en.json` · `de.json` |
| Helper | `apps/web/lib/i18n.ts` |
| Hook | `useUserPrefs().t` / `useT()` |

`setLocale` writes localStorage and `lang`; React re-renders chrome with the matching dictionary.

## Namespaces (Phase 1)

`common` · `nav` · `pages` · `settings` · `login` · `home`

Further hub/editor strings migrate incrementally; unset keys fall back to `defaultLocale` then the key itself.

## Out of scope

- Vision/transcript payload language (Whisper `VIDEON_WHISPER_LANGUAGE`)
- URL locale segments
